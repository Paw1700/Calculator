# Calculator (in progress)
 
PWA app calculator with built in units converter.

## Technologies

* Angular 15
* HTML
* CSS

## Purpose of creating an app

Some OS don't have calculator app (example iPadOS), so I create one to test my skills using Angular framework and use this app for my own goals

## How to run

This app can be run like any other Angular projects. But remember to use `npm install` first.
